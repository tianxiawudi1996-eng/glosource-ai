## 1. 제품 개요

**GloSource AI**는 한국의 소규모 제조·건설업체가 해외 공급자를 안전하게 발굴하고 직발주할 수 있도록 돕는 **AI 글로벌 소싱 에이전트**다.

### 핵심 가치 제안

> "중국·해외 공장에서 직발주하고 싶은데, 사기업체인지 어떻게 알아요?"  
> → GloSource AI가 공급자 신뢰도를 AI로 분석하고, 문의 이메일까지 자동 작성해준다.

### 기술 인프라 (SafeDoc AI 재활용)
- Next.js 16 + React 19 + TypeScript
- Gemini AI (웹 검색 그라운딩 기능 활용)
- Vercel 배포 (현재: safedoc-ai.vercel.app → 도메인 변경 예정)

## 2. 문제 정의

### 타겟 사용자
**소규모 제조·건설업체** (직원 5~50명, 연매출 5억~50억 원)

- 건설 현장 자재, 기계 부품, 설비를 수입하거나 OEM으로 조달하려는 업체
- 서원토건 같은 중견 건설사 포함
- 해외 직발주 경험 없거나 초보 수준

### 핵심 페인포인트 (우선순위 순)
1. **공급자 신뢰도 검증 불가** ← 가장 치명적 장벽 (사기 피해 경험/공포)
2. 언어 장벽 (중국어/영어로 협상 불가)
3. 수입 통관 절차 모름
4. 좋은 공급자를 어디서 찾는지 모름

### 현재 대안의 한계
| 대안 | 한계 |
|------|------|
| 알리바바 직접 검색 | 영어 장벽, 수천 개 결과에서 신뢰 업체 선별 불가 |
| 1688.com | 전부 중국어, 한국 결제 수단 없음 |
| 구매대행 서비스 | 수동·느림·비쌈, 전략적 소싱 불가 |
| KOTRA | 공무원 속도, 소량 발주 대응 안 됨 |

## 3. 제품 범위 (MVP)

### 핵심 기능 4가지 (MVP에 포함)

#### 기능 1. AI 공급자 탐색
- 사용자 입력: 제품명/스펙 (한국어), 필요 수량, 예산, 국가 선호
- Gemini 웹 검색 그라운딩으로 Alibaba/Made-in-China/Global Sources에서 공급자 자동 탐색
- 결과: 관련 공급자 3~7개 후보 리스트

#### 기능 2. AI 공급자 신뢰도 분석
- 각 공급자에 대해:
  - 설립 연도 및 운영 기간
  - 인증서 (ISO, CE, etc.) 보유 여부
  - 거래 리뷰 수 및 평점 분석
  - 적신호(Red flag) 탐지: 가격이 비상식적으로 저렴, 연락처 불명확 등
- 결과: 한국어 신뢰도 점수 (0~100) + 근거 + 주의사항

#### 기능 3. 한국어 소싱 리포트 생성
- 공급자 비교표 (최대 5개사)
- 각사 신뢰도 분석 요약
- 추천 공급자 1순위 + 이유
- 면책 고지 (AI 분석 결과는 참고용, 최종 판단 본인 책임)
- **PDF 다운로드** (회사명·날짜 포함)

#### 기능 4. 문의 이메일 자동 초안
- 선택한 공급자에게 보낼 RFQ(견적요청서) 이메일 자동 생성
- 언어 선택: 영어 / 중국어 (간체)
- 포함 항목: 제품 스펙, 수량, 납기, 결제 조건, 샘플 요청 여부
- 복사 및 텍스트 편집 가능

### MVP 제외 항목 (향후 추가)
- 실시간 공급자 DB 구축 (별도 크롤링 인프라 필요)
- 답장 번역 자동화 (이메일 연동 필요)
- 통관·관세 자동 계산 (관세청 API 연동 필요)
- 결제 에스크로 (전자상거래법 복잡)
- 모바일 앱

## 4. 사용자 흐름

```
[입력] 소싱 요청
  ↓
사용자가 한국어로 입력:
  - 제품/자재명 (예: "SS400 강판 6T, 1,000장")
  - 희망 단가 범위 (선택)
  - 원산지 선호 (중국 / 동남아 / 유럽 / 상관없음)
  - 월 발주 예상 빈도

[처리] AI 소싱 분석 (30~60초)
  ↓
Gemini 웹 검색:
  → 관련 공급자 후보 탐색
  → 각 공급자 정보 수집·분석
  → 신뢰도 채점
  → 문의 이메일 초안 생성

[출력] 소싱 리포트
  ↓
  - 추천 공급자 순위 (1~5위)
  - 각사 신뢰도 점수 + 근거
  - Red flag 경고
  - PDF 저장 버튼
  - 이메일 초안 (영어/중국어) 복사 버튼
```

## 5. 수익 모델

### 플랜 구조
| 플랜 | 가격 | 포함 |
|------|------|------|
| 무료 체험 | 0원 | 1회 소싱 분석 (결과 미리보기, PDF 잠금) |
| 스타터 | 10만원/월 | 소싱 분석 10회/월, PDF 다운로드, 이메일 초안 |
| 프로 | 30만원/월 | 무제한 소싱 분석, 이력 관리, 이메일 초안 (한/영/중), 우선 지원 |
| 팀 | 70만원/월 | 5계정 공유, 현장별 분류, 전담 지원, 세금계산서 |

### 목표 수익 계산
- **목표**: 10만원/일 = 300만원/월
- **달성 시나리오**: 프로 10개사 = 300만원/월 ✓
- **초기 영업 대상**: 서원토건 협력사 네트워크 (건설업체 집중)

## 7. 법적 고려사항

### 면책 고지 (UI 필수 포함)
- AI 분석은 참고용이며, 최종 거래 결정은 사용자 본인 책임
- 특정 공급자를 보증하지 않음
- Alibaba/1688 등 플랫폼 정책 변경에 따라 정보 정확도 변동 가능

### 고려할 규제
- 「전자상거래 등에서의 소비자보호에 관한 법률」 — 직접 결제 중개 시 적용
- MVP는 정보 제공 서비스에 한정 → 직접 결제·에스크로 없음 → 규제 외
- 개인정보보호법 — 사용자 입력 데이터 최소 수집
