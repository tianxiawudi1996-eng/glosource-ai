## Usage notes
- Match [category] to evidence of what they're building (don't guess blindly).
- One CTA only: the free sample report. Don't pitch pricing in the first touch.
- Log every send + contact provenance; run `npm run growth:outreach:preflight` before any cold-email batch.
- If they request the report → send within the hour; then ask one interview question: "would a tool that does this for any category you search be worth ~$19–49/mo?"
- Never claim suppliers are "verified." Say "candidates / signals to verify."
