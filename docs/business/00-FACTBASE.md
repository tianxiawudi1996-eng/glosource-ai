## B. 제품 — 실제로 작동하는 것 (검증됨)

**한 줄 정의**: 해외 B2B 바이어가 한국 공급사(제조사) 후보를 90초 내에 찾고, 그 후보가 **실존하는 정부 등록 제조사인지 즉시 대조**해 주는 리서치 도구.

**경계(중요)**: 소싱 대행사·감사기관·물류사·거래 중개자가 **아니다**. 리서치 도구다. (문서 전반에서 이 경계를 지킬 것 — 넘으면 규제·책임 문제 발생)

### B-1. 핵심 기술 — AI 발굴 → 정부 레지스트리 교차검증 (차별점의 본체)

경쟁 제품 대부분은 AI가 뱉은 공급사 목록을 그대로 보여준다. GloSource는 그 목록을 **정부 원장에 대조**한다.

| 대조 원장 | 적재 건수 | 검증 내용 |
|---|---|---|
| 식약처 화장품 등록업체 | **32,109건**(등록 행 기준) / **회사 28,237곳**(사업자번호 기준) | 제조업 허가 보유 여부 + 사업자등록번호 + 공장 주소 |
| 식약처 CGMP 적합업체 | **176건** | GMP 인증 여부 (사업자번호 매칭) |
| HACCP 인증 식품제조사 | **40,906건** | 식품 안전 인증 |
| 의료기기 제조/수입업체 | 적재됨 | 제조 vs 수입 판별 |
| 건강기능식품 업소 | 적재됨 | — |
| 의약외품 업체 | 적재됨 | — |
| **국세청 사업자 상태** | **실시간 API** | 계속사업자 / 휴업 / **폐업** 실시간 조회 |

### B-1-a. ⭐ 핵심 통계 — "등록업체 대부분은 공장이 아니다" (2026-07-13 프로덕션 DB 실측)

이 사업의 **필요성을 증명하는 단 하나의 숫자**다. 모든 문서에서 이 값을 쓴다.

| 기준 | 전체 | 그중 `화장품제조`(공장) | 제조업 비율 |
|---|---|---|---|
| **회사 (사업자등록번호 기준 — 이 값을 쓸 것)** | **28,237곳** | **4,115곳** | **14.6%** |
| 등록 행(row) 기준 (참고용) | 32,109건 | 4,120건 | 12.8% |

> **⇒ 식약처에 화장품 업체로 등록된 회사 28,237곳 중 실제 제조 시설을 가진 곳은 4,115곳(14.6%)뿐이다. 나머지 85.4%는 `화장품책임판매`(브랜드/유통)로, 공장이 아니다.**

**⚠ 반드시 회사(사업자번호) 기준을 쓸 것.** 행 기준(12.8%)은 **중복 계산**이다 — 제조사는 통상 `화장품제조`와 `화장품책임판매` **양쪽에 모두 등록**되므로 같은 회사가 두 번 잡힌다(실제 사례: 나우코스, 한국코스모, 코스메디크, 씨티케이, 코스맥스 전부 양쪽 등록). 정부 서식에 잘못된 산출근거를 쓰면 안 된다.

**산출식**: `SELECT count(DISTINCT bizrno), count(DISTINCT bizrno) FILTER (WHERE induty='화장품제조') FROM kr_cosmetics_firms` → 28,237 / 4,115

### B-2. 이 구조가 실제로 잡아내는 것 (실증 사례)

- **"제조사 vs 중개상" 판별**: 화장품의 경우 `화장품제조`(공장)와 `화장품책임판매`(브랜드/유통)를 구분한다. 후자는 공장이 아니다.
- **실증**: 큐레이션 과정에서 웹 검색 상위에 뜬 "저MOQ 한국 공장" 중 상당수가 **공장이 아니었다.**
  - 한 업체는 업계 최저 수준 MOQ(300개)를 광고했으나 **식약처 제조업 등록이 존재하지 않았다** → 배지 부여 거부
  - 다른 업체는 `화장품책임판매`만 등록 → 브랜드이지 공장이 아님
  - 영어권 검색 상위 다수가 **소싱 에이전시**(남의 공장을 재판매)
- **폐업 리스크 차단**: 국세청 실시간 조회로 폐업/휴업 업체는 배지 대신 경고 표시.

### B-3. 큐레이션된 검증 공급사 DB (프로덕션 실적재)

| 카테고리 | 건수 | 검증 상태 |
|---|---|---|
| K-Beauty | 7 | 전원 식약처 `화장품제조` 등록 확인 + 사업자번호 보유 |
| K-Food | 16 | 전원 HACCP 원장 대조 확인 |

## D. 실적 — **전부 0** (은폐 금지)

| 지표 | 실제 |
|---|---|
| 유료 고객 | **0** |
| 매출 | **0원** |
| 리드 접촉 | **0** |
| 고객 인터뷰 | **0** |
| 샘플 리포트 요청 | **0** |
| 결제 발생 | **0** |

**검증된 것**: 제품 라이브(`GET /en` HTTP 200), 결제 인프라 연동 완료, 정부 레지스트리 검증 엔진 실동작.
**검증 안 된 것**: 시장 수요(PMF), 지불 의사, 획득 채널.

> **이 상태의 정직한 표현**: "기술은 구현·검증되었고, 시장 검증은 이제 시작한다."
> 예비창업·R&D 지원사업은 **매출 0이 결격사유가 아니다.** 오히려 정부지원금의 사용 목적이 바로 이 검증이다.
> **투자 유치(VC)는 이 상태에서 어렵다** — 문서에서 이 점을 호도하지 않는다.

> ⚠ TAM/SAM/SOM을 계산할 때 **위 수치에서 논리적으로 도출 가능한 범위**만 쓴다. "글로벌 소싱 시장 XX조" 같은 출처 없는 숫자 금지.

## F. 고객(ICP) — 정의됨 (실제 문서 `docs/growth/outreach-icp.md`)

**핵심 질문 하나**: "이 대상이 한국 공급사를 *찾아야만* 하는가?"

## H. 절대 금지 (모든 문서 공통)

1. **고객·매출·전환율을 지어내지 않는다.** 0은 0으로 쓴다.
2. **"검증된 공급사"라는 표현을 근거 없이 쓰지 않는다.** 정부 원장 대조 근거가 있는 건에만 쓴다.
3. **K-Fashion은 검증 불가**임을 숨기지 않는다.
4. **출처 없는 시장 규모 숫자를 쓰지 않는다.** (E항 외의 숫자 금지)
5. **특허·수상·제휴를 지어내지 않는다.** 없으면 "없음" 또는 "계획".
6. **AI가 공급사를 '국가 API로 발굴한다'고 쓰지 않는다.** 발굴은 AI(웹), **대조가 정부 API**다. 이 순서를 뒤집는 과장 금지.
7. 재무 추정은 **가정을 명시한 추정치**로 표기하고, 실적처럼 쓰지 않는다.
