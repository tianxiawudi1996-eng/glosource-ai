# 상표등록출원서 초안

> 이 문서는 특허로 전자출원 입력용 초안이다. 실제 제출 전 출원인 주소, 특허고객번호, 주민등록번호/법인번호 등 개인정보는 특허로 화면에서 직접 입력한다.

## 1. 출원 구분

| 항목 | 내용 |
|---|---|
| 권리구분 | 상표 |
| 출원방식 | 국내 상표 전자출원 |
| 표장유형 | 문자상표 |
| 우선권주장 | 없음 |
| 심사유형 | 일반심사 |

## 2. 출원인

| 항목 | 내용 |
|---|---|
| 출원인 | 김무빈 또는 확정된 사업 주체 |
| 주소 | 특허로 제출 시 직접 입력 |
| 특허고객번호 | 발급 후 기재 |

주의: 공동대표 또는 화장품 업계 대표자를 세울 계획이면 상표 출원인 명의를 먼저 확정한다. 상표권은 나중에 이전할 수 있지만 비용과 서류가 추가된다.

## 3. 출원 표장 1순위

| 항목 | 내용 |
|---|---|
| 표장 | GloSource AI |
| 표장 설명 | 영문 문자로 구성된 서비스명 |
| 출원 우선순위 | 최우선 |

## 4. 추천 상품류

### 42류

GloSource AI의 핵심이 SaaS, AI 소프트웨어, 데이터 검증 플랫폼이므로 42류는 필수다.

지정서비스업 후보:

| 번호 | 지정서비스업 |
|---:|---|
| 1 | 서비스형 소프트웨어업[SaaS] |
| 2 | 플랫폼 서비스형 소프트웨어업[PaaS] |
| 3 | 인공지능 소프트웨어 개발업 |
| 4 | 컴퓨터 소프트웨어 설계업 |
| 5 | 데이터베이스 설계 및 개발업 |
| 6 | 전자데이터 저장업 |
| 7 | 컴퓨터 데이터 분석 서비스업 |
| 8 | 클라우드 컴퓨팅 서비스업 |

### 35류

해외 바이어 대상 공급사 리서치, 사업정보 제공, 시장조사 성격을 보호하려면 35류가 필요하다.

지정서비스업 후보:

| 번호 | 지정서비스업 |
|---:|---|
| 1 | 사업정보제공업 |
| 2 | 상업정보제공업 |
| 3 | 시장조사업 |
| 4 | 사업자료분석업 |
| 5 | 온라인을 통한 사업정보제공업 |
| 6 | 수출입 관련 사업정보제공업 |

주의: `수출입업무대행업`은 GloSource의 사업 경계와 맞지 않을 수 있다. GloSource는 거래대행이 아니라 리서치 도구이므로 처음 출원에서는 피하는 편이 안전하다.

## 5. 최소 출원안

| 안 | 표장 | 류 | 최초 비용 |
|---|---|---:|---:|
| 최소안 | GloSource AI | 42류 | 46,000원~52,000원 |
| 권장안 | GloSource AI | 42류 + 35류 | 92,000원~104,000원 |
| 확장안 | GloSource AI, GloSource | 각 42류 + 35류 | 184,000원~208,000원 |

## 6. 표장 2순위

| 항목 | 내용 |
|---|---|
| 표장 | GloSource |
| 목적 | 약칭 및 브랜드 확장 방어 |
| 진행 | 예산 가능 시 2차 출원 |

## 7. 정부사업 문서 반영 문구

출원 전:

> `GloSource AI` 문자상표 출원 준비 중이며, 서비스형 소프트웨어업 및 사업정보제공업을 중심으로 42류와 35류 출원을 진행할 계획이다.

출원 후:

> `GloSource AI` 문자상표 출원 완료(출원번호: 추후 기재). 지정상품/서비스업은 서비스형 소프트웨어업[SaaS], 인공지능 소프트웨어 개발업, 사업정보제공업 등 GloSource AI의 실제 사업범위에 맞춰 구성하였다.

## 8. 제출 전 확인사항

- KIPRIS에서 `GloSource AI`, `GloSource`, `글로소스`, `GLOSOURCE` 유사상표 검색
- 출원인 명의 확정
- 42류/35류 중 최초 출원 범위 확정
- 지정서비스업 10개 이하로 정리
- 고시상품명칭 사용 가능 여부 확인
