# PLAN

## Current Operating Order

1. 배포 안전: 브랜치 검증과 운영 승격을 분리하고 수동 승인 게이트를 강제한다.

3. 증거 안전: 공개 예시·수치·인증·성과 주장을 재현 가능한 근거 또는 명확한 예시로 제한한다.
4. 하네스 보정: 코드 baseline, 검증일, 시장 증거일, 외부 차단사항을 분리 기록한다.

## Risks

- 기본 브랜치의 큰 dirty worktree로 인해 변경 소유권이 혼재될 수 있다.
- 기존 성장 산출물에 예시 리드가 포함되어 실제 KPI와 혼동될 수 있다.
- 샘플 리포트가 실제 공급사 검증처럼 보일 위험이 있다.
- 외부 플랫폼 데이터 없이는 K-DEFENSE 반응을 판정할 수 없다.
- 자동화가 외부 발송까지 넘어가면 브랜드·스팸·개인정보 위험이 있다.
