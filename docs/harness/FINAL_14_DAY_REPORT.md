## 3. 입증된 것 / 입증되지 않은 것

### 입증됨

- 영문 랜딩과 Polar checkout 3종은 접근 가능하고 현재 상품 ID가 응답한다.
- 현재 가격은 Starter $39, Pro $99, Business $249이며 표시·checkout·구조화 데이터가 같은 원천을 쓴다.
- 결제가 발생하면 이력을 기록하고 계정 삭제 후 법정 결제 기록을 비식별 상태로 보존하는 경로가 있다.
- 공급사 배지는 실제 원장 근거가 없거나 충돌하면 실패한다.
- 예시 리드, 자기 댓글, 가짜 trust score, 추정 사업자번호를 성과로 계산하지 않는다.

### 입증되지 않음

- 해외 인디 뷰티 바이어가 이 문제를 지금 해결하려는지.
- shortlist에 $99 이상을 지불할지.
- 샘플이 미팅·결제로 전환되는지.
- K-DEFENSE 조회가 itch 클릭·플레이·교육 수요로 전환되는지.

## 4. 가설 수정

- GloSource 기존 가설: 제품과 샘플을 준비하면 자동 성장 루프가 수요를 만든다.
- 수정: 제품 개선보다 **창업자 주도 100명 수요 인터뷰/판매**가 먼저다. 자동화는 증거 기록과 품질 차단에만 사용한다.
- K-DEFENSE 기존 가설: 역사 쇼츠 조회가 게임·교육 IP 관심으로 이어진다.
- 수정: 조회수는 성공 KPI가 아니다. 댓글 키워드·교육자료 요청·플레이 전환을 측정하고 그 전에는 게임 기능을 만들지 않는다.
