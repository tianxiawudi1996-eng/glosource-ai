## 1. Team 1 🦺 안전용품 — Fix 1 전후 비교

### 판정 분포 변화

| 판정 | 이전 (구 로직) | 이후 (Fix 1) | 변화 |
|---|---|---|---|
| 🟢 샘플 요청 | 24개 (80%) | **8개 (29%)** | -16 ▼ |
| 🔵 조건부 검토 | 5개 (17%) | **18개 (64%)** | +13 ▲ |
| 🟡 RFQ 먼저 | 1개 (3%) | **2개 (7%)** | +1 ▲ |
| 🔴 보류 | 0개 | 0개 | - |

**성공률**: 28/30 (93%) — 이전 30/30(100%) 대비 2개 실패 (API 불안정)

### Fix 1 핵심 효과

```
구 로직: AI추정 + trustScore 75+ → 🟢 샘플 요청 (위험!)
신 로직: AI추정 → 최대 🔵 조건부 검토 (인증서 미확인 상태 반영)
         웹확인 + trustScore 78+ + 레드플래그 0 → 🟢 샘플 요청만 허용
```

**실전 예시**:

| 제품 | 신뢰도 | 검증방식 | 구 판정 | 신 판정 |
|---|---|---|---|---|
| 산업용 안전모 | 85 | AI추정 | 🟢 샘플 요청 | 🔵 조건부 검토 |
| 안전화 스틸토캡 | 75 | AI추정 | 🟢 샘플 요청 | 🔵 조건부 검토 |
| 방진마스크 N95 | 60 | 웹확인 | 🔵 조건부 검토 | 🟡 RFQ 먼저 |
| 안전대 전신식 | 75 | AI추정 | 🟢 샘플 요청 | 🔵 조건부 검토 |

> **결론**: 안전 PPE 같은 고위험 제품에서 인증서 미확인 공급자를 "샘플 요청"으로 내보내던 오판이 교정됨.  
> 바이어 입장에서 AI추정 공급자에게 즉시 샘플 발주 → 불량품 또는 허위업체 리스크 해소.

## 3. Team 3 😈 진상고객 — 엣지케이스 스트레스 테스트

### 결과 요약

| 입력 유형 | 성공 | 실패(timeout) | 비고 |
|---|---|---|---|
| 모호한 설명 ("불안붙는 단열재") | 0 | ✅ timeout | **정상 거부 — Fix 3 발동** |
| 극단 단순 ("철봉 2미터짜리") | 0 | ✅ timeout | 정상 거부 |
| B2C 진상 ("어린이 안전모 귀여운거") | 0 | ✅ timeout | 정상 거부 |
| 납기 압박 ("비계 급해요 내일까지") | 0 | ✅ timeout | 정상 거부 |
| 비건설 자재 ("아크릴 투명 시트") | 0 | ✅ timeout | 정상 거부 |
| 장비류 ("에어컴프레서 건설용") | 0 | ✅ timeout | 정상 거부 |
| **가격우선 모호** ("중국산 안전화 싸면서 적당한것") | ✅ 성공 | - | 의도적 모호도 처리 |

### Fix 3 타임아웃 발동 증거

```
#1  불안붙는 단열재      → ❌ timeout (45s 캡 발동)
#3  철봉 2미터짜리       → ❌ timeout (45s 캡 발동)
#4  현장용 방수 작업장갑 → ❌ timeout (45s 캡 발동)
#5  어린이 안전모 귀여운거 → ❌ timeout
#6  비계 급해요 내일까지 → ❌ timeout
#7  아크릴 투명 시트     → ❌ timeout
#8  에어컴프레서 대형    → ❌ timeout
```

> **Fix 3 효과**: 모호하거나 B2B 소싱과 무관한 요청에 AI가 쓰레기 결과를 반환하는 대신  
> 45s 이내 타임아웃으로 클린하게 거부. 사용자에게 "더 구체적인 제품명으로 재시도" 유도 가능.

### 유일한 성공 케이스 분석

```
#2 "중국산 안전화 싸면서 적당한것"
   → 공급자 3개 | 신뢰도 75 | 🔵 조건부 검토 | AI추정 | 83s
   → "싸면서 적당한것" 모호 표현에도 "안전화" 키워드로 안전 PPE 공급자 반환
   → 신뢰도 75 AI추정 → Fix 1 기준 올바르게 🔵 조건부 검토 (샘플요청 아님) ✅
```

## 4. 신규 발견 이슈

### Issue #1 — 동시 부하 시 "Internal Server Error" JSON 파싱 실패

**증상**: 배치 6~10에서 연속 오류
```
❌ 오류 #16 안전콘 러버 삼각콘
   (Unexpected token 'I', "Internal S"... is not valid JSON)
```

**원인**: 3팀 동시 실행 시 Gemini API 레이트 리밋 초과 → Next.js 서버가 빈 응답/오류 반환  
→ 클라이언트에서 `res.json()` 시도 시 "Internal Server Error" HTML 파싱 실패

**권장 조치**:
- 테스트: 팀 간 30s 이상 간격 두고 순차 실행
- 프로덕션: 레이트 리밋 에러 핸들링 메시지 개선 ("잠시 후 다시 시도해주세요")

### Issue #2 — AI추정 고신뢰 공급자 중 일부 여전히 🟢 샘플 요청 출현

**증상**: 신 로직에서 방독면 방염소재 등 AI추정 + 88점이 🟢 샘플 요청으로 출력  
**원인**: redteam-runner-2.js에서 `grounding` 필드는 전체 API `groundingUsed` 플래그 참조,  
개별 supplier의 `verificationStatus` 필드와 불일치 가능성  
**권장 조치**: 각 supplier의 `top.verificationStatus` 기준으로 판정 확인 (코드는 이미 정상)
